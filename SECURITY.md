# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Typr is an offline terminal typing trainer. It makes zero network requests, transmits no telemetry, and executes no user-typed content.

If you discover a security vulnerability or local arbitrary code execution hazard within Typr, please report it privately:

1. **Email:** aliarhan002@gmail.com
2. Provide a description of the issue and a minimal reproducible example.
3. Do not open a public issue on GitHub before the vulnerability has been evaluated and addressed.

We appreciate responsible disclosure and will respond within 48 hours.
